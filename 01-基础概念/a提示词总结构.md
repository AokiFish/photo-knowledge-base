# AI 摄影提示词总结构

> 版本：1.0  
> 适用对象：没有专业摄影基础、希望用自然语言稳定生成摄影感图像的创作者  
> 核心目标：把“我想要一张好看的照片”拆成 AI 能理解、自己也能检查和修改的具体指令。

---

## 1. 先理解一件事：提示词不是摄影术语越多越好

提示词的任务不是炫耀术语，而是**减少歧义**。

例如：

- 模糊：`一个漂亮的女孩，很高级，很有电影感`
- 更清楚：`一位年轻女性站在雨后的东京街头，半身肖像，人物位于画面右侧，左侧留出街道空间，柔和的霓虹反光，低饱和青蓝与暖橙色，真实皮肤纹理，电影剧照质感`

第二个描述更有效，不是因为它更长，而是因为它交代了主体、场景、构图、光线、色彩和质感。

**新手原则：先把画面说清楚，再考虑相机型号、胶片型号等进阶词汇。**

## 2. 一条摄影提示词的七个模块

推荐把提示词拆成七个模块。不是每次都必须写满；根据任务挑选即可。

|模块|要回答的问题|例子|
|---|---|---|
|1. 主体与场景|画面里是谁/是什么？在哪里？正在做什么？|一位年轻女性站在雨后的城市街头|
|2. 景别与视角|拍多近？从什么方向看？|半身肖像，平视视角|
|3. 构图与画面组织|主体放哪里？画面如何平衡？|人物位于右侧，左侧留白|
|4. 摄影表达|希望画面呈现什么摄影语言？|人像摄影，自然抓拍感|
|5. 光线|光从哪里来？软还是硬？|柔和侧光，霓虹灯在湿地面形成反光|
|6. 色彩与质感|色调、反差、细节是什么？|低饱和青蓝与暖橙，保留真实皮肤纹理|
|7. 约束与输出|哪些东西要避免？需要什么画幅？|自然手部，避免塑料皮肤，竖幅 4:5|

### 可直接套用的模板

```
[主体与场景]。
[景别与视角]，[构图安排]。
[摄影表达或风格]。
[光线描述]。
[色彩与质感]。
[画幅或必要约束]。
```

英文提示词模板：

```
[Subject and setting].
[Shot size and camera angle], [composition].
[Photographic approach or style].
[Lighting].
[Color palette and texture].
[Aspect ratio and essential constraints].
```

## 3. 从最简单的版本开始

### Level 1：只交代画面

```
一位年轻女性在雨后的城市街头，真实人像摄影。
```

适合：先测试模型能否理解主体和场景。

### Level 2：加入构图和光线

```
一位年轻女性站在雨后的城市街头，半身肖像，平视视角，人物位于画面右侧，
左侧保留街道空间。柔和侧光，湿润路面反射霓虹灯，真实人像摄影。
```

适合：希望控制画面布局和氛围时。

### Level 3：加入色彩与质感

```
一位年轻女性站在雨后的城市街头，半身肖像，平视视角，人物位于画面右侧，
左侧保留街道空间。柔和侧光，湿润路面反射霓虹灯。低饱和青蓝色阴影与
克制的暖橙色灯光，真实皮肤纹理，细腻但不过度磨皮，电影剧照质感，竖幅 4:5。
```

适合：对最终视觉风格有更明确要求时。

### Level 4：最后才加入相机、镜头或胶片词

```
一位年轻女性站在雨后的城市街头，半身肖像，平视视角，人物位于画面右侧，
左侧保留街道空间。自然抓拍式人像摄影，柔和侧光，湿润路面反射霓虹灯。
低饱和青蓝色阴影与克制的暖橙色灯光，真实皮肤纹理，细腻但不过度磨皮。
35mm 街头摄影的空间感，柔和高光过渡，细微胶片颗粒，竖幅 4:5。
```

注意：相机和胶片名称不一定会让模型准确模拟真实器材。它们是**风格提示**，需要通过实际生成结果验证。

## 4. 模块一：主体与场景

尽量说明以下三项：

1. **主体**：谁或什么？年龄感、外观、材质等是否重要？
2. **动作/状态**：正在做什么？静止、行走、回头、奔跑？
3. **环境**：室内、街道、森林、棚拍背景、海边？

不必写无关细节。如果你最关心的是产品，先讲清产品；如果你最关心的是人物表情，先把表情写清楚。

## 5. 模块二：景别与视角

景别决定画面离主体有多近，视角决定观众从哪里看主体。

- 远景：环境占主导，人物较小。
- 全身：人物整体可见。
- 中景：通常从膝部或腰部附近向上，具体范围可按需求说明。
- 半身：人物上半身为主。
- 近景：面部或主体细节更突出。
- 特写：强调眼睛、手、产品细节等局部。

视角常用词：

- 平视：观众与主体大致处于同一高度。
- 俯拍：从上方看主体。
- 仰拍：从较低位置向上看主体。
- 侧面：主体侧向镜头。
- 正面：主体面向镜头。
- 过肩视角：从人物肩后观察前方对象。

不要只写“高级视角”这类抽象表达，尽量说明具体怎么拍。

## 6. 模块三：构图

构图是安排画面中主体、背景和空白的方式。新手最常用的控制方法：

- 居中构图：主体在画面中央，稳定、直接。
- 三分构图：主体靠近画面三分之一位置，画面更有空间感。
- 对称构图：左右或上下结构相对平衡。
- 留白构图：刻意保留空白，适合极简、海报和产品图。
- 前景遮挡：用近处物体形成层次。
- 引导线：利用道路、栏杆、建筑线条等引导视线。
- 框中框：通过门、窗、拱门等框住主体。
- 负空间：主体周围有意保留的空余区域。

可执行的描述比术语更重要：

- 术语版：`三分构图`
- 具体版：`人物位于画面右侧三分之一处，左侧留出大面积虚化街景作为负空间`

## 7. 模块四：摄影表达

这一模块描述“像哪一类照片”，例如：

- 自然人像摄影：重点是人物状态、肤色与自然光。
- 街头纪实摄影：重视真实瞬间、环境关系和自然抓拍感。
- 时尚编辑摄影：造型、姿态、光线和视觉态度更突出。
- 产品摄影：产品轮廓、材质、反光和可读性优先。
- 风光摄影：强调空间、天气、层次和自然色彩。
- 电影剧照：强调叙事氛围、光线方向、色彩关系和情绪。

“电影感”本身很宽泛，最好再说明是冷峻雨夜、温暖室内、逆光剪影，还是低调悬疑氛围。

## 8. 模块五：光线

写光线时，先回答三个问题：

1. 光从哪里来：窗边、正面、侧面、背后、顶部？
2. 光是什么性质：柔和还是强烈？明亮还是昏暗？
3. 光照到哪里：脸部、背景、产品边缘、雾气或地面？

例子：

- `阴天漫射光，阴影边缘柔和`
- `窗户侧光照亮人物面部，另一侧保留自然阴影`
- `逆光勾勒头发轮廓，面部仍然清晰可见`
- `小型硬光源形成清晰阴影，复古直闪快照感`
- `柔和顶侧光表现玻璃瓶的轮廓与高光`

## 9. 模块六：色彩与质感

色彩可以用“主色 + 辅色 + 饱和度 + 反差”来表达。

例如：

`主色为柔和米白与暖棕，低饱和，反差适中，高光过渡柔和。`

质感可以描述：

- 真实皮肤纹理
- 细腻织物纹理
- 金属边缘高光
- 玻璃折射与反射
- 细微胶片颗粒
- 柔和高光晕染
- 清晰但不过度锐化
- 轻微运动模糊
- 低反差阴影

注意：不要把互相冲突的要求堆在一起，例如同时要求“极低反差”和“强烈硬阴影”，除非你明确知道要什么特殊效果。

## 10. 模块七：约束与输出

约束只写真正重要的事项：

- 主体数量与身份特征保持一致。
- 手部和身体结构自然。
- 背景不要抢主体注意力。
- 不要过度磨皮或塑料质感。
- 产品轮廓、标志或文字需要准确时，明确说明。
- 画幅比例：方形 1:1、竖幅 4:5、竖屏 9:16、横幅 3:2 或 16:9。

不要堆叠几十条“不要”。优先写最可能影响成片的三到五条约束。

## 11. 一次只改一个主要变量

如果第一张图不理想，先判断问题在哪：

- 主体不对：改主体描述。
- 构图不对：改位置、景别或视角。
- 光线不对：只改光线。
- 色彩不对：只改色调和饱和度。
- 质感不对：只改皮肤、材质、颗粒或锐度。

例如，第一轮与第二轮只比较光线：

A：`柔和的窗边自然光`  
B：`强烈的侧面阳光，形成清晰阴影`

其他描述保持不变。这样才能知道变化来自哪里。

## 12. 新手常见错误

### 错误一：只写抽象形容词

`高级、绝美、顶级、惊艳、大片感`

这些词含义宽泛，模型可能无法按你的预期执行。改成可观察的视觉特征。

### 错误二：一次塞入太多摄影术语

相机、镜头、胶片、灯光、摄影师风格、后期滤镜全部一起写，会让你无法判断哪个因素起作用。

### 错误三：相互矛盾

例如同时写“自然柔光”和“极硬的正面闪光”，或者“背景清晰”又“极浅景深”。如果需要混合效果，说明每种效果分别出现在哪里。

### 错误四：忽略构图

主体和风格写得很丰富，却没说明主体放在哪里，结果经常是主体居中、画面拥挤或背景杂乱。

### 错误五：把器材名称当成保证

写上某款相机并不保证模型能准确还原该机型的色彩或镜头特性。先用视觉语言描述结果，再把器材名称作为可选补充。

## 14. 一页式检查清单

生成前，快速检查：

- [ ] 我明确写出了主体和场景吗？
- [ ] 我说明了拍摄距离或景别吗？
- [ ] 我说明主体在画面中的位置了吗？
- [ ] 我描述了主要光线吗？
- [ ] 我说明了主要色彩或质感吗？
- [ ] 有没有互相冲突的要求？
- [ ] 我是不是一次加入了太多新变量？

**记住：先明确画面，再控制构图和光线，最后才是器材、胶片和细节。**
