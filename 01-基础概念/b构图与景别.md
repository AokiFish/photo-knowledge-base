# 构图与景别

> 版本：1.0  
> 本文件目标：让没有摄影基础的人，能用简单的中文控制 AI 图片中的拍摄距离、观看角度、主体位置和画面空间。

---

## 1. 为什么构图比相机型号更值得先学？

同一个人、同一条街，可能因为拍摄距离、主体位置和视角不同，变成完全不同的照片。

- 远景让环境和故事更重要。
- 特写让表情或细节更重要。
- 低机位会让主体显得更有力量。
- 大面积留白会让画面更安静。
- 主体居中会显得直接、稳定；偏离中心则可能产生空间感或张力。

对 AI 图片来说，构图词能直接帮助模型组织画面。因此新手先学习构图，通常比一开始背相机型号更有效。

## 2. 景别：镜头离主体有多近？

景别描述画面里主体占多大。不同工具对景别边界的理解可能略有差异，因此应把景别词与具体画面范围一起写。

<details> <summary>景别速查</summary>

|景别|画面重点|适合场景|可复制描述|
|---|---|---|---|
|极远景|环境、地貌、空间尺度|风景、孤独感、宏大场景|主体很小，广阔环境占据画面绝大部分|
|远景|人物与环境关系|旅行、电影场景、街景|全身人物处于环境中，背景信息清晰可辨|
|全身|人物整体造型与姿态|穿搭、角色设计、时尚|从头到脚完整呈现人物，脚部不被裁切|
|中景|人物动作与环境兼顾|对话、生活方式、街拍|画面从大腿或腰部附近向上，人物动作自然|
|半身|表情、上身造型|人像、社交头像、时尚|从腰部附近向上，脸部与肩部清晰|
|近景|面部和情绪|肖像、情绪表达|面部占画面主要区域，保留少量肩部|
|特写|眼睛、手、产品局部等|美妆、细节、产品|只突出眼睛、手部或指定细节|
|大特写|极局部纹理|眼部、材质、微距细节|极近距离呈现睫毛、皮肤纹理或材质细节|

</details>

### 新手最常用的四种景别

- **全身**：看穿搭、动作、角色整体。
- **中景**：看人物动作，也保留一些环境。
- **半身**：适合人物肖像，主体和背景容易平衡。
- **特写**：适合强调情绪、眼神或产品细节。

### 常见问题：人物总是被裁切

不要只写 `full body`。可以补充：

`完整呈现人物从头到脚，双脚与头顶都留在画面内，人物四周保留适当空间。`

如果模型仍然裁切，简化背景、减少无关要求，并尝试更宽松的画幅。

## 3. 机位与观看角度

机位是摄影机相对主体的位置。角度会影响人物的气势、空间感和观众的感受。

|机位/角度|视觉效果|可复制提示词|
|---|---|---|
|平视|自然、平等、容易产生真实感|平视视角，镜头与人物眼睛大致同高|
|低机位/仰拍|主体更有力量，建筑显得高大|从较低位置向上拍摄，人物具有力量感|
|高机位/俯拍|主体显得更小，空间关系更明显|从主体上方俯拍，清楚呈现周围环境|
|鸟瞰|强调图案、道路和空间布局|从高处垂直向下观察场景|
|地面机位|强调地面延伸、鞋履或建筑高度|摄影机接近地面，地面纹理向远处延伸|
|正面|直接、有交流感|主体正面朝向镜头|
|侧面|强调轮廓、姿态和方向|主体侧向镜头，清楚呈现侧脸轮廓|
|三分之四侧面|比正面更有立体感，又保留面部信息|人物身体与面部略微转向一侧，呈三分之四角度|
|过肩视角|让观众像在现场观察|从前景人物肩膀后方看向另一主体|
|主观视角|模拟角色亲眼所见|第一人称视角，画面像由角色亲自看到|

**建议：**人像初学先用“平视 + 正面或三分之四侧面”。想要力量感再尝试低机位；想突出环境再尝试高机位。

## 4. 构图：主体应该放在哪里？

### 4.1 居中构图

主体位于画面中央，视觉明确、稳定、正式。

适合：证件感肖像、角色设定、极简头像、产品主视觉。

```
正面肖像，主体位于画面中央，左右空间平衡，背景简洁。
```

### 4.2 三分构图

把画面想象成横竖各分成三份，主体靠近其中一条分割线或交点。

适合：街头摄影、旅行人像、环境肖像。

```
人物位于画面右侧三分之一处，左侧保留环境空间，视线前方留出空间。
```

### 4.3 对称构图

主体或建筑沿画面中轴形成近似对称关系，容易产生秩序感、仪式感或庄严感。

适合：建筑、正面肖像、极简产品图。

```
正面视角，主体居中，背景建筑沿中轴对称排列，画面整洁而克制。
```

注意：如果你想要自然抓拍，不必强行对称。

### 4.4 留白构图与负空间

画面中有意保留不被主体占据的区域。留白可以是天空、墙面、虚化背景或空旷街道。

适合：极简摄影、海报、品牌视觉、安静的人像。

```
人物位于画面左下方，右侧保留大面积干净墙面作为负空间，画面安静简洁。
```

### 4.5 前景构图

让近处物体进入画面边缘，形成前、中、后景层次。

适合：街拍、森林、咖啡馆、旅行摄影。

```
前景有轻微虚化的树叶，中景人物清晰，背景街道柔和虚化，画面具有自然层次。
```

### 4.6 引导线构图

道路、栏杆、建筑边缘、桥梁或光影线条把视线引向主体。

适合：街景、建筑、电影场景。

```
街道两侧的线条向远处汇聚，引导视线落在画面中央的人物身上。
```

### 4.7 框中框

利用窗户、门框、拱门或树枝围出一个视觉框架。

```
通过老建筑的门框拍摄人物，门框形成自然边框，主体位于框内。
```

### 4.8 对角线构图

主体、道路或动作沿斜线展开，画面更有动势。

```
人物沿画面对角线方向行走，背景线条形成斜向延伸，画面具有运动感。
```

### 4.9 层次构图

明确区分前景、中景、背景，避免画面像平面贴图。

```
前景是虚化的花朵，中景主体清晰，背景是柔和的树林，空间层次自然。
```

## 5. 视线方向和主体动作

人物不一定要看镜头。视线方向会影响照片的情绪和空间安排。

- 看镜头：直接、自信、交流感强。
- 看向画外：自然、沉思、叙事感。
- 低头：安静、内省，容易显得柔和。
- 回头看：带有瞬间感和故事性。
- 闭眼：安静、放松，但要确认不是要求清晰眼神的场景。
- 行走中抓拍：更生活化，适合街拍与纪实。
- 静态站姿：稳定，适合时尚或角色展示。

可复制描述：

```
人物没有直视镜头，而是自然地看向画面左侧，身体微微转动，姿态放松。
```

## 6. 焦点与背景关系

### 主体清晰，背景虚化

适合肖像、产品和需要突出单一主体的画面。

```
人物眼睛清晰对焦，背景柔和虚化，主体与环境分离。
```

### 主体与环境都清晰

适合建筑、风光、旅行记录和环境肖像。

```
人物和周围建筑都保持清晰，完整呈现场景环境。
```

### 选择性对焦

画面只让某个重要细节清晰。

```
焦点落在玻璃瓶的标签和瓶口，前后景逐渐虚化。
```

不要把“背景虚化”理解成所有照片都必须有的效果。背景需要传递信息时，保持清晰可能更合适。

## 7. 画幅比例与构图的关系

|画幅|常见用途|构图提醒|
|---|---|---|
|1:1 方形|头像、社交媒体、极简产品图|主体可以居中，也适合简洁留白|
|4:5 竖幅|人像、时尚、社交平台图片|适合半身与较紧凑的全身构图|
|2:3 竖幅|传统人像、全身摄影|为人物上下留出空间|
|9:16 竖屏|手机壁纸、短视频封面|注意头顶、脚部与字幕安全区|
|3:2 横幅|传统摄影、旅行、纪实|人物与环境较容易平衡|
|16:9 横幅|电影感画面、宽幅风景|适合横向空间和环境叙事|

画幅不是纯粹的输出设置，它会影响主体能否完整呈现。需要全身时，竖幅通常更方便；需要展示两个人或宽阔环境时，横幅往往更合适。

## 8. 用构图解决常见问题

|生成结果的问题|优先修改什么|可以尝试的描述|
|---|---|---|
|主体太小|景别|半身肖像，人物占据画面主要区域|
|人物被裁切|取景范围与边缘空间|完整呈现头顶与双脚，四周保留适当空间|
|画面太挤|留白与背景|简化背景，主体周围保留干净空间|
|画面太空|景别或环境层次|镜头靠近主体，增加适度前景层次|
|主体总在正中央|主体位置|人物位于画面左侧三分之一处|
|背景太乱|景深与背景简化|背景元素减少，轻微虚化，不抢主体注意力|
|人物显得呆板|姿态和视线|身体略微转向一侧，视线自然看向画外|
|场景没有空间感|前中后景|增加柔和前景，主体清晰，背景向远处延伸|
|产品不突出|主体占比与光线|产品占画面主要区域，轮廓清晰，背景简洁|

## 9. 八个可直接使用的构图小案例

### 案例 A：自然人像

```
半身人像，平视视角，人物位于画面右侧三分之一处，
左侧保留柔和虚化的公园环境，人物自然看向画外，
阴天漫射光，背景不抢主体注意力。
```

### 案例 B：极简头像

```
正面近景肖像，主体居中，头部完整，背景为纯净浅灰色，
左右视觉平衡，眼睛清晰对焦，画面简洁克制。
```

### 案例 C：全身穿搭

```
全身时尚摄影，从头到脚完整呈现人物，脚部不被裁切，
人物站在简洁建筑背景前，身体微微转向一侧，
地面和头顶保留适当空间。
```

### 案例 D：街头抓拍

```
中景街头摄影，人物在行走中自然回头，主体靠近画面左侧，
视线前方留出空间，前景有轻微虚化的路人轮廓，
自然抓拍感，避免摆拍姿态。
```

### 案例 E：电影雨夜

```
中远景，人物站在画面右侧，左侧是延伸到远处的湿润街道，
路面反射霓虹灯，建筑线条引导视线通向远处，
人物轮廓清楚，画面有明显前中后景。
```

### 案例 F：极简产品

```
单个香水瓶位于画面中央偏下位置，周围保留大面积负空间，
背景干净，瓶身完整呈现，轮廓与标签清晰，
柔和侧光表现玻璃质感，画面安静高级。
```

### 案例 G：风光

```
广阔山谷远景，前景有岩石，中景是山坡，远景是层叠山脉，
地平线位于画面上方三分之一处，云层形成自然引导线，
空间深远，色彩自然。
```

### 案例 H：建筑

```
正面广角建筑摄影，建筑位于画面中央，垂直线条保持端正，
前景整洁，左右结构平衡，柔和日光呈现建筑材质。
```

## 10. 最有效的练习方法：固定主体，只换构图

选一个简单主体，例如“一个红色玻璃瓶”，连续生成以下版本：

1. 居中构图
2. 左侧三分构图
3. 大面积留白
4. 前景遮挡
5. 低机位
6. 高机位

每次只修改构图相关描述，其他提示词保持一致。对比时观察：

- 主体是否更突出？
- 画面是否更平衡？
- 空间感是否更明确？
- 是否更符合你想要的情绪？
- 哪一种构图最适合这个主体？

## 11. 构图提示词积木库

按需要选取，不要全部堆进去。

**景别**  
`wide shot` · `full-body shot` · `medium shot` · `waist-up portrait` · `close-up` · `extreme close-up`

**角度**  
`eye-level view` · `low-angle shot` · `high-angle shot` · `top-down view` · `ground-level perspective`

**构图**  
`centered composition` · `rule-of-thirds composition` · `symmetrical composition` · `negative space` · `foreground framing` · `leading lines` · `frame within a frame` · `diagonal composition`

**主体位置**  
`subject positioned on the left third` · `subject positioned on the right third` · `centered subject` · `ample space around the subject`

**景深与空间**  
`sharp focus on the subject` · `softly blurred background` · `clear environmental details` · `distinct foreground, midground and background`

## 12. 记住这五条

1. 景别决定你看什么，机位决定你从哪里看，构图决定它如何出现在画面里。
2. 先用具体中文描述画面，再补充英文术语。
3. 一张图通常只需要一个主要构图思路。
4. 不要为了“专业”强行使用三分法；居中和对称也可能是最合适的选择。
5. 如果构图不对，先修改取景、主体位置和留白，不要急着更换相机型号。
